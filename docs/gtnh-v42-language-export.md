# v42：简体中文与条件坐标导出

更新配套 Viewer 与 Worker 后重启 GTNH。协议升级为 **21**，不能混用 v41 及更早的 Worker。

## 界面语言

`Settings / 设置 → Language / 语言` 可选择 **English** 或 **简体中文**。
首次使用跟随系统语言：中文系统默认简体中文，其余默认英语；手动选择后保存，下次启动沿用。
切换后菜单、常用对话框和探矿显示立即更新，不需要重新打开世界。

覆盖主菜单、维度、已支持的结构类型、探矿状态与提示、筛选、坐标导出、生物群系图片导出等界面文字。
英语原文作为缺失译文的回退；诊断日志和第三方错误详情保留原文。
矿脉、流体和游戏提供的生物群系名称仍取自运行中的模组语言资源。
切换 Viewer 语言不改动游戏语言，也不改变世界种子、注册 ID、坐标和用户输入。

翻译表为 UTF-8 的 `src/main/resources/amidst/i18n/zh_CN.json`，英语原文作为键，便于后续补充语言。

## 条件导出

在 `世界 → 导出坐标` 中选择维度，再选择 **矿脉** 或 **地下流体**，下方会出现导出条件：

| 条件 | 矿脉 | 流体 |
|---|---|---|
| 类型 | 当前维度矿脉下拉列表 | 当前维度流体下拉列表 |
| 高度 | 最低、最高 Y，与矿脉高度范围相交即匹配 | 不适用 |
| 记录状态 | 可选仅导出已记录矿脉 | 每个输出点标明 CURRENT / INITIAL |
| 已耗尽 | 默认排除，可勾选包含 | 由最低 L/Op 控制 |
| 最低产出 | 不适用，不虚构矿脉总量 | 大于或等于设定 L/Op 的区块 |
| 点位数量 | 一个矿脉中心点 | 默认每个流体田一个最佳区块，可选全部符合条件区块 |
| 坐标数量上限 | 默认 1,000，可设置 1–10,000 | 同左 |

打开时优先使用当前维度、标点模式、类型选择及最低 L/Op。导出条件可以单独调整，不影响地图筛选。
`重置筛选` 恢复全部类型、默认高度和数量上限等条件。选择普通 POI 类型时隐藏探矿条件。
CSV、JourneyMap ZIP 和直接导入游戏使用相同筛选结果。直接导入仍最多支持 2,000 个点位。

流体导出坐标为符合条件的**区块中心**，名称附带 L/Op 和数据来源。
最佳区块只在所选范围内比较；边界包含起点、终点，范围外更高产的区块不会替代范围内结果。
若多个区块产出相同，按固定扫描顺序选择一个。L/Op 表示每次操作的产出，不是总可采储量。
矿脉点名称附带记录来源和高度范围；未记录点仍为种子候选，沿用 v39 的精度限制。

达到坐标数量上限后立即停止后续区域查询，并在结果消息中明确提示。
这表示已导出扫描到的前若干点，**不表示找到了最近的点，也不表示已搜完整个范围**。
类型和储量过滤能减少数据传输和输出量；没有结果的巨大区域仍需要扫描，建议限制范围。
进度显示已扫描区域数量，可随时取消。最大范围仍限制为 4,096 次地图区域查询。

## 实现与验证

- 导出条件随请求发送到 Worker，在收集点位时过滤。矿脉导出跳过图标生成；
  非目标流体在计算区块产出及读取现有记录前排除。没有新增区块生成或流体耗尽操作。
- Viewer 再次检查条件、范围与数量上限，分批扫描；达到上限后不再发起下一次查询。
- 测试覆盖负坐标、范围内最佳区块、全部区块、阈值等号、ID 精确匹配、高度相交、
  记录与耗尽条件、提前停止、取消、大范围拒绝和请求中的筛选字段。
- 中文测试检查全部 42 个维度与坐标类型名称覆盖、语言切换保留用户输入和 ID、整数输入校验，
  并生成矿脉／流体条件面板图像以检查排版。
- 继续运行原有回归测试、真实 GT 7,680 区块产出对照、43 种维度图标验证及 Worker 安装映射检查。

本轮未替换游戏中的模组或重启游戏，新包仍需安装后进行完整游戏实测。
