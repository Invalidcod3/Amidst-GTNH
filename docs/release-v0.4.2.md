# Amidst-GTNH v0.4.2

本版适配 **GTNH 2.9.1 / RWG2 2.0.9 大陆模式**，继续支持 **GTNH 2.9.0 / RWG2 2.0.6** 和 **RWG-Alpha 1.5.3**。Viewer 与 Worker 版本均为 **0.4.2**，协议保持 **31**。

## 更新

- 按实际安装的 RWG2 构建选择算法和完整字节码核验清单。未知构建仍明确报错。
- 世界类型自动显示 `RWG2 Smooth (GTNH 2.9.0)` 或 `RWG2 Smooth (GTNH 2.9.1)`，只列出当前实例可运行的 Smooth 版本，同时保留 RWG-Alpha。旧的 Smooth 默认设置会跟随当前实例；地图选项和导出名称同步显示版本。
- Worker 握手新增可选的 `rwg2Version` 字段。旧 Worker 缺少字段时仍可连接，显示通用 Smooth 名称；未知构建不冒充已核验版本。
- 支持新版群系大小倍率、可选气候带、群系／大陆偏移及每大陆污染之地分布设置；洞穴、村庄、矿井与地下湖开关改读对应版本的配置类。
- 同步河流交汇处地标的归属与去重规则、暮色传送门概率、距世界原点的最小距离及未激活概率。
- 未激活暮色水池使用**蒲公英**图标，已激活传送门保留**虞美人**图标；两者共用原有“自然暮色传送门”图层，名称区分状态。
- 核对 2.9.1 植被配置与生成代码。150 个条目的群系准入规则与 2.9.0 一致，目录标明共同适用范围。选植被后自动勾选群系、启用高亮，完整群系列表与原有操作保持不变。
- 更新地图缓存算法标识，升级后自动重算，不复用旧预测瓦片。
- 补充[网页端与 Wiki 后续同步说明](reference/rwg2-version-sync.md)，两个独立项目留待后续同步。

版本识别以实际加载的 RWG2 模组为准，不依赖启动器实例名。一个游戏进程只加载一版 RWG2；查看另一版地图时，请启动对应 GTNH 实例并重新连接 Viewer。

## 安装

关闭游戏，移除旧 Worker，把 `amidst-gtnh-worker-v0.4.2.jar` 放入 `mods`，仅保留一份。
重启游戏，使用同包的 `amidst-gtnh-biomes-v0.4.2.jar` 或 `run-viewer.bat`。
既有配置可保留；修改生成设置后需要重启游戏。

## 验证与边界

使用实际 RWG2 2.0.6、2.0.9 JAR 做原生算法对照，包括最终群系、地下地形、出生点和并行采样；2.0.9 另检查缩放、气候带、偏移、污染之地和暮色水池设置。具体依据与复现方法见 [2.9.1 适配记录](reference/gtnh-2.9.1.md)。

发布验证：Viewer 240 项通过（10 项开发工具默认禁用），Worker 124 项通过、无跳过。包括版本识别、握手向后兼容、错误版本拒绝和旧名称解析。两个 RWG2 版本分别匹配 25,600 个最终群系点；2.0.9 的配置对照另外匹配 20,000 点。RWG-Alpha 1.5.3 与 GTNH 2.9.1 随包 GregTech 5.09.54.275 的参考测试通过。

地标仍是生成候选，后续装饰和玩家改动可能影响现场。普通水方块不能证明水池结构存在；只有已加载位置出现暮色传送门方块时才标为已记录的激活传送门。检查不会加载、生成或修改游戏区块。

本版未增加 Et Futurum 新增沉船、废弃传送门的定位图层。自动化对照不等同于在完整 2.9.1 客户端内逐项实测。
此前功能见 [v0.4.1](release-v0.4.1.md)，使用方法见 [操作指南](usage.md)。
