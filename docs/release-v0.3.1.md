# Amidst-GTNH v0.3.1

本页描述当前源码与整合发布包，包含冷启动、维度、小行星、出生点及维护整理等全部已完成变更。
发行版本 **0.3.1**，协议 **25**；归档标识 **v0.3.1-rebuild-20260915**。旧归档保留，文件名以本页为准。

## 安装与兼容性

下载 `Amidst-GTNH-v0.3.1-rebuild-20260915.zip`，解压到独立目录。

1. 关闭 GTNH，移除旧 Worker，放入包内 `amidst-gtnh-worker-v0.3.1.jar`，仅保留一份。
2. 重启游戏。使用 Java 17 或更新版本运行包内 `run-viewer.bat`，Viewer 不放入 `mods`。
3. 同时使用包内配套两端；已有缓存无需删除。

目标环境为 GTNH 2.9.0-beta-3，其他版本尚未完成兼容性验证。界面仍显示 v0.3.1，
请用包名、SHA-256 校验文件及 `build-info.json` 区分本次重构建与旧包。

## 已完成变更

- **启动和退出**：模组与配置指纹在后台准备，可选缓存请求失败后继续加载瓦片；关闭 Viewer 时同步关闭它自动打开的控制台。
- **缓存与视图**：群系磁盘缓存、地图中心与筛选恢复；按存档和生成输入区分，校验失败退回查询。
- **验证和导出**：生物群系、结构、矿脉的独立预测对照；无法验证单列。支持填写起点与数量后由近到远导出，移除坐标输入外侧方括号。
- **路径点与刷新**：双击自动加入 JourneyMap，默认关闭，使用真实维度和位置；切换存档后重新检查地牢选址，避免旧结果永久排除候选。
- **维度预览**：补齐更多维度群系，冥王星按地表材质配色；核对汉化名称，Everglades 使用“废土世界”。
- **小行星矿脉**：使用小行星的原生选择规则和 X/Y/Z 中心，区分小矿石与混合矿石；末地按原生分区查询，保留高度到导出与 JourneyMap。
- **出生点**：移除固定原点回退，优先读取同种子已加载世界的记录；独立估算重放地形、地表和洞穴，按提供器规则续算。地图及已选信息一起刷新。
- **源码维护**：拆分采样接口、实现及出生点任务缓存，移除生产代码中失效的旧启发式接口，统一相关模块排版并补充回归测试。
- **文档整理**：当前安装、使用和维护说明统一；详细算法按功能归类，旧迭代记录进入历史目录。

## 已知限制

- 纯种子的出生点仍是估算，尚未重放全部结构、地物覆盖和第三方生成事件。种子 `-8138049151491905853` 与存档出生点的偏差尚未确认修复。
- 小行星、结构和矿脉标记代表候选；缺少已生成证据时不能保证存在。未知高度仅用于导航。
- 地图缓存不支持完全离线浏览；部分末地查询依赖对应存档已加载的末地状态。

操作见 [使用说明](usage.md)，算法依据见 [专题资料](reference/README.md)。
