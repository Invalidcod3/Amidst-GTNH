# v43 中文字体修复

地图信息框此前固定使用 Arial，中文翻译虽已正确读取，绘制时仍因字体缺少字形而显示方块。

- 地图信息框、坐标网格、配置选择页和错误窗口改用 Java 的逻辑无衬线字体，允许系统为中文等字符选择备用字体。
- 保持原来的字号、粗细；信息框的宽高计算与绘制继续使用同一字体，适配中英文混排。
- 语言资源仍按 UTF-8 读取，不需要修改系统编码。

关闭旧 Viewer，运行 `amidst-gtnh-biomes-v0-2-v43.jar` 即可。协议仍为 21；已安装 v42 Worker 时无需替换 Worker 或重启游戏。更早的 Worker 仍须升级到协议 21。

字体回退依赖运行系统安装的字体；标准中文 Windows 环境自带所需字体。本次使用真实地图文字组件验证简体中文、英文、混排和 100% / 150% 缩放下的绘制，未启动完整 GTNH 游戏。
