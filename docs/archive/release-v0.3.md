# Amidst-GTNH v0.3

> 历史记录：安装要求、协议号及验证结论属于当时版本。当前状态见[发布说明](../release-v0.3.1.md)。

历史发布说明。当前安装与更新内容请阅读 [v0.3.1](../release-v0.3.1.md)。

v0.3 带来矿脉和地下流体探矿图层，补全星系等维度入口，并加入简体中文界面与条件坐标导出。

## 主要更新

- **探矿图层**：在维度切换下方选择结构、矿脉或流体。矿脉显示图标、名称、组成、高度和坐标；流体使用不同颜色区分，放大后显示区块网格与逐区块产出，背景群系图适当调暗。
- **下拉筛选**：从当前维度的矿脉或流体目录中选择类型，无需手写名称；地下流体可按最低 L/Op 筛选。
- **维度与图标**：补全星系等探矿维度，修复未加载维度遗漏，提供 GTNH 维度标记方块图标；排除没有矿脉、流体和 POI 的维度。
- **中英文界面**：在“设置 → 语言”中切换简体中文或 English，保存选择；修复地图信息框中文显示为方块的问题。
- **条件坐标导出**：矿脉可按类型、Y 范围、记录状态及耗尽状态筛选；流体可按类型、最低 L/Op 筛选，并选择每田最佳区块或全部符合条件区块。支持 CSV、JourneyMap ZIP 和直接导入旅行地图。
- **限制导出数量**：默认最多 1,000 个点，可调整为 1–10,000；达到上限后停止查询，支持取消。直接导入最多 2,000 点。
- **地图与响应改进**：保留 RWG/BOP 群系重放、罗斯 128b 与 Deep Dark 采样优化、地图瓦片缓存及游戏线程分段查询等改进。

## 下载与安装

推荐下载 `Amidst-GTNH-v0.3.zip`，内含两个 JAR、Windows 启动脚本及使用说明。

1. 关闭 GTNH，移除 `mods` 目录中的旧 Amidst Worker，放入 `amidst-gtnh-worker-v0.3.jar`。只保留一个 Worker。
2. 启动 GTNH；Worker 默认启用，已有配置中手动关闭的设置会保留。
3. 使用 Java 17 或更新版本运行 `amidst-gtnh-biomes-v0.3.jar`；Windows 可双击 `run-viewer.bat`。

Viewer 在游戏外运行，请将 **Worker JAR** 放入 `mods`，将 **Viewer JAR** 保留在独立目录。

v0.3 通信协议为 **21**。从 v41 及更早测试版升级到 v0.3 时须更新两端；当时使用 v42／v43 Worker 的用户可以只更新 Viewer。此兼容性不适用于 v0.3.1。

## 使用与精度说明

- 未取得 Visual Prospecting 服务端记录的矿脉显示为**种子候选**，受真实地形、放置失败和重试影响，并不保证该坐标实际存在矿脉。
- **L/Op 是每次操作的流体产出量，不是总可采储量**。无法读取当前记录时显示初始值，并区分数据来源。
- 部分新增维度在 v0.3 中提供探矿功能，但尚无经过验证的生物群系底图；补齐工作见 v0.3.1。
- 导出按区域扫描顺序取得点位；达到上限不表示已搜完范围，也不代表结果是最近的点位。建议按需要限制范围。
- 游戏提供的矿脉、流体和群系名称沿用模组语言资源；切换 Viewer 语言不会更改游戏语言。

本版针对 GTNH 2.9.0-beta-3 的相关接口开发，参考 GregTech 5.09.54.133、Visual Prospecting 1.5.39 和 RWG alpha 1.5.2；未验证 GTNH 2.8 系列。构建包含自动化测试、真实模组算法对照与安装 JAR 映射检查；本次正式版打包未进行完整游戏实测。
