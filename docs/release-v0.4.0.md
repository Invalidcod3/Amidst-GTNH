# Amidst-GTNH v0.4.0

本版正式支持 **GTNH 2.9.0 的 RWG2 Smooth 大陆模式**，保留 **RWG-Alpha**。
发行版本为 **0.4.0**，通信协议为 **31**。开发阶段的 0.4.1–0.4.12
属于内部试用编号，其已验证改动统一收录于本正式版。

## 本版更新

- 新建种子与筛种器可选择 RWG2 Smooth / RWG-Alpha；存档按自身生成器读取，模式之间隔离缓存。
- 支持 EndlessIDs 扩展群系编号，修复海洋、红树林等移植群系的显示；调整 Tropics、Jungle、
  Jungle Mesa、Jungle Canyon、Oasis、Lush Desert、寒冷群系、殷红 Inferno 与紫黑 Tainted Land 的配色。
- 保留每 4 格的精细采样，底图后台并行最高 64 路；复用海洋、山地与河流邻域计算，不扩大采样间隔。
- 底图先显示，结构随后补齐；修复旧结构混入新画面、区块变化引起整屏刷新、启动大量分配和大视野断连问题。
- 磁盘缓存写入与清理移到有界后台队列，减少两种 RWG 模式共有的周期性停顿。
- 底图完成后结构请求可立即扩展到最多 4 路；洞穴计算使用独占后台上下文，空闲工作线程自动退出。
- 按开启图层选择结构算法；暮色门与河道小游戏都关闭时跳过河道定位，下界门与熔岩小游戏同理。
  关闭刷怪笼地牢后不再执行其洞穴重放。共享随机序列仍保留已开启结构所需的前序计算。
- 接入海底神殿、自然暮色门、下界门、两类洞室小游戏，以及村庄、要塞、矿井、Roguelike、Thaumcraft 等候选。
  三类 LootGames 分开显示；暮色门使用虞美人图标，下界门使用紫色传送门图标。
- 补齐 RWG2 随机种子出生点估算，修复出生点标记与跳转；匹配存档的记录出生点优先。
- 修复 RWG2 大视野下矿脉／流体图层空白和报错，保留取消、筛选、坐标导出与 JourneyMap 导入。

## 安装与升级

1. 解压 `Amidst-GTNH-v0.4.0.zip` 到独立目录。
2. 关闭 GTNH，移除旧 Worker，将包内 `amidst-gtnh-worker-v0.4.0.jar` 放入 `mods`，只保留一份。
3. 重启 GTNH，使用 Java 17 或更新版本运行 `run-viewer.bat`；Viewer JAR 不放入 `mods`。
4. 新建种子默认选择 RWG2 Smooth；可在世界类型列表切换 RWG-Alpha。

请同时更新两端。测试期也使用过 v0.4.0 文件名，因此需要实际替换文件，不能只凭文件名判断已更新。
无需清空旧群系缓存；地图仍须连接 Worker，不能离线浏览。结构、矿脉和流体不会永久写入群系缓存。
详细操作、并发设置与排障见[使用说明](usage.md)。

## 兼容性与预测边界

- 本版参考环境为 GTNH 2.9.0、RWG2 2.0.6、RWG-Alpha 1.5.3 与 GregTech 5.09.54.265。
  RWG 1.5.2 的已知适配保留；其他 RWG2 版本和其他整包版本需要重新验证。
- RWG2 支持大陆模式 `RWG2_CONTINENTS`，不将普通 `RWG2` 世界类型视为同一算法。
- 结构标记通常表示候选，可能受到地形装饰、其他结构、模组事件及玩家改动影响。
  未加载区域不当作已确认生成；预览不会主动生成或加载实际区块。
- RWG2 熔岩洞室装饰避开火山范围，不能用其中的小游戏标记代替火山定位。
- 出生点估算不包含第三方事件与装饰的全部影响，也不等同于玩家首次进入位置。
- 地图隐藏设置不限制独立导出或准确性验证。关闭某项标记时，其他开启项仍可能需要共享定位。

## 验证与发布文件

发布构建执行两端回归测试、本机 RWG / RWG2 / GregTech 参考算法对照、协议及版本一致性检查，
并验证 Worker 的安装映射。Viewer **226 项通过、10 项开发工具测试跳过**；Worker **121 项全部通过**。
并行原生地下重放与串行结果一致；关闭图层跳过算法、取消与缓存失效都有回归覆盖。
用户已反馈筛种器速度达到预期；本次打包没有重新执行完整游戏存档验收，性能不代表所有机器的固定倍数。

- `Amidst-GTNH-v0.4.0.zip`：配套 JAR、启动脚本、说明和许可证。
- `Amidst-GTNH-v0.4.0-source.zip`：与本次构建对应的工作树源码。
- `Amidst-GTNH-v0.4.0-SHA256SUMS.txt`：两个 ZIP 与配套 JAR 的校验值。
- 两个 JAR 也可单独上传为 GitHub Release 附件。

包内 `build-info.json` 和 `source-sha256.txt` 保存测试计数、基础提交和逐文件来源。
算法边界见 [RWG2 实现记录](reference/rwg2-adaptation-plan.md)，原始测量见[开发历史](archive/rwg2-development-history.md)。
