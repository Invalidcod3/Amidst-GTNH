维护规则：用户可见行为更新到使用说明，完整发行状态更新到发布说明，源码边界更新到开发维护。
同一版本的后续修订合并到这些文档，避免每个小改动都增加一份平行的使用或安装说明。
只有需要保留原始测量、源码依据或阶段结论时才增加详细记录。
