# Amidst-GTNH v0.4.1

本版在 v0.4.0 的地图功能基础上新增 **GTNH 2.9.0 植被筛选**，支持 **RWG-Alpha 1.5.3** 与 **RWG2 2.0.6 大陆模式**。
Viewer 和 Worker 发行版本统一为 **0.4.1**，通信协议保持 **31**。此前曾使用相同编号的内部试用构建不等同于本次正式包，请使用本次配套文件。

## 本版更新

- 在原生物群系筛选控件加入“植被条件…”入口，按原版／模组花朵、潘马斯菜园与果树、其他树木查询候选群系。
- 支持中英文搜索、按模组名搜索、分类和多选；可匹配任一植物，也可要求全部条件成立。
- 点击“应用高亮”会自动勾选匹配群系并启用高亮。原列表保持完整，“全部／特殊／清空”、手动点选和启用开关保留原有行为。
- Alpha 与 RWG2 独立使用各自的群系池和装饰规则，避免把另一种生成器特有的群系列入结果；匹配使用运行时名称、标签和实际编号，兼容同名的 BOP 原始／移植实例。
- 保留植物选择供下次编辑，搜索和分类切换不丢失已选项；取消不应用草稿，切换维度会关闭本次植被高亮。
- 随包提供[分布分析](reference/vegetation.md)和[逐项规则表](reference/vegetation-catalog.md)，说明潘马斯枫树、橄榄树、Botania 花朵维度等特殊情况。

## 安装与升级

1. 将 `Amidst-GTNH-v0.4.1.zip` 解压到独立目录，关闭旧 Viewer 和 GTNH。
2. 移除 `mods` 中旧 Worker，放入包内 `amidst-gtnh-worker-v0.4.1.jar`，仅保留一份。
3. 重启 GTNH，使用 Java 17 或更新版本运行 `run-viewer.bat`；Viewer JAR 不放入 `mods`。
4. 在地图右下角的群系筛选控件中打开“植被条件…”，选好植物后应用高亮。

原配置可保留，无需手动清空群系缓存。Worker 本次仅同步发行版本，植被规则和交互实现在 Viewer，未修改通信协议。
更多操作见[使用说明](usage.md)，已有地图功能及精度边界见 [v0.4.0 发布说明](release-v0.4.0.md)。

## 数据范围与验证

植被索引包含 150 个条目，其中 140 个具有已核实的生成规则；其余明确标注未核实。规则依据 GTNH 2.9.0 默认配置，不读取自行修改的植物配置，也不进行区块装饰重放或植物方块验证。
当前支持主世界、下界、暮色森林和罗斯 128b 中已收录的规则；地面、光照、高度及概率仍影响实际生成。候选群系不表示每处都能找到对应植物。

发布构建运行两端自动化测试、发行版本／协议检查和 Worker 安装包映射检查；具体通过与跳过数量记录在包内 `build-info.json`。
植物匹配、Alpha/RWG2 隔离、自动勾选与原群系控件行为均有回归测试；本次打包不宣称完成全新游戏进程和逐种植物的完整实地验收。
