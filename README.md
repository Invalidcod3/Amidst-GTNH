# Amidst-GTNH

## 注意事项
本项目主要为Amidst的GTNH特供版，目前主要由Codex编写，有很多问题，欢迎有人发PR来完善代码。
需要Java 21+。

## 功能
- 主世界的生物群系和主要结构定位。
- 下界的生物群系和结构定位。
- 末地的HEE生物群系和结构定位，包括龙研的混沌岛屿。
- 星系的主要星球和地牢等结构定位。
- 稀有矿脉定位（待修复）。

## 使用方法
1. 解压文件。
2. 把worker模组放入你的模组文件夹。
3. 打开游戏后进入config/amidstgtnhworker.cfg文件，把enabled设置为true。
4. 再次启动游戏后双击bat，或者在命令行输入java -jar <amidst本体> -gtnh-worker。
