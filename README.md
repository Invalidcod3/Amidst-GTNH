# Amidst-GTNH

为原项目Amidst的GTNH特供分支。

*原项目：https://github.com/toolbox4minecraft/amidst

## 注意事项
目前本项目的源码全由Codex构建而成，欢迎提Pr来完善源码以及进一步的扩展功能。

## 功能
- 主世界生物群系和主要结构可定位。
- 下界生物群系和结构可定位。
- 末地的HEE生物群系和地牢可定位，当然混沌岛屿也可以定位。
- 暮色魔法地图移植。
- 星系主要星球的地牢和结构可定位。包括暗物质小行星。

## 原理
考虑到1:1的把GTNH各种模组的算法全部搬入Amidst内不是很现实，所以本项目实质上是用Amidst作为前端，用模组来实时调用游戏内的函数来实现最基础的种子查看功能的。

## 潜在问题
- 生物群系ID会有问题，需要至少加载一次土卫六的维度，待修。
- 矿脉定位有问题。暂时不要打开下界或罗斯128b这两个维度。

## 如何使用
1. 下载并Release文件。
2. 把amidst-gtnh-worker-v[].jar文件放入游戏的Mod文件夹。
3. 启动游戏（不需要打开任意存档，在主界面即可）。
4. 双击run-gtnh-amidst.bat启动Amidst。
